申请SSL证书步骤


# 申请通配符证书

先使用命令申请dns证书

```bash
certbot certonly -d *.qiuming.xyz --manual --preferred-challenges dns --server https://acme-v02.api.letsencrypt.org/directory
```

然后需要验证DNS TXT记录，这个过程会生成一个字符串需要填写到域名服务商提供的服务中，aliyun的话直接填写个解析记录`_acme-challenge.qiuming.xyz`到域名解析服务中。

等待验证就好。


# 通配符证书复制移动

```bash
sudo cp /etc/letsencrypt/live/qiuming.xyz -aL ./
```

| 参数组合 | 符号链接处理方式                 | 元数据保留 | 递归复制 |
| -------- | -------------------------------- | ---------- | -------- |
| cp -a    | 保留符号链接本身                 | 是         | 是       |
| cp -L    | 不递归，仅复制链接目标内容       | 否         | 否       |
| cp -aL   | 递归复制，跟随符号链接并复制目标 | 是         | 是       |
| cp -R -L | 递归复制，跟随符号链接并复制目标 | 否         | 是       |
